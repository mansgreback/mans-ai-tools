# Måns AI Tools for Glyphs

Four plugins for Glyphs 3 and 4 that do the slow parts of type design for you, with the models running on a server:

| Plugin | Does |
|---|---|
| **Måns AI Kerning** | Kerns your font. |
| **Måns AI Spacing** | Spaces your font. |
| **Måns AI Anchors** | Places your anchors. |
| **Måns AI Variable Font** | Makes a variable font from a single style font, every node kept. |

Free on A–Z a–z, 10 runs a day per plugin. One license, bought once, unlocks all four on every glyph, unlimited:
**https://aringtypeface.com/mans-tools/**

## Install

Through **Window ▸ Plugin Manager** in Glyphs, or download the pack from the page above, unzip and double-click each
`.glyphsPlugin`. The plugins need the **vanilla** module (Plugin Manager ▸ Modules). Restart Glyphs.

## Use

- AI Kerning, AI Spacing, AI Anchors: **Glyph** menu. AI Variable Font: **File** menu.
- Internet access is required. Manual: https://aringtypeface.com/mans-tools/manual
- Full version: click **License key** in any plugin, paste the key, **Activate**. One key, one computer at a time.

## Privacy

Font and plugin data will be sent to, stored and processed on the aringtypeface.com server: the options you have selected, and the metrics and outlines needed. Only the current master and the glyphs your chosen options require are sent; no other masters, glyphs or font data. Your license key and computer ID are sent for validation. No data is shared with any third party, but it may be used to improve the product.
